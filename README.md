# Naglis Bražėnas — Portfolio

A lightweight static portfolio built with HTML, CSS and JavaScript.
No framework, build step, backend, paid hosting or subscription is required.

## Preview locally
Open `index.html` in a browser.

## Add detailed project reports (PDF)
The selected projects include links to separate PDF reports. To make those links work:
1. Create a folder named `docs` beside `index.html`.
2. Put the relevant PDF files in it using these exact filenames:
   - `trading-system-report.pdf`
   - `parliamentary-transcripts-report.pdf`
   - `lyrics-topic-modelling-report.pdf`
   - `muffin-chihuahua-report.pdf`
3. If you do not have a report for a project yet, either leave the link for later or remove that `<a class="report-link">...</a>` line from `index.html`.
4. Upload the `docs` folder along with the website files to GitHub. GitHub Pages will serve the PDFs at the linked paths.

The PDFs are not included in this starter ZIP; add your own final reports.

## Before publishing
1. Review all project descriptions and confirm the team/personal labels.
2. Confirm the regression project details and update its placeholder in `index.html`.
3. Replace `YOUR_EMAIL@example.com`, `YOUR-LINKEDIN` and `YOUR-GITHUB` with your real contact links.
4. Add your public repositories where appropriate.

## Publish free with GitHub Pages
1. Create a **public** GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js` and the `docs` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Your site will be available at `https://YOUR-USERNAME.github.io` after publishing completes.

GitHub Pages is free for public repositories on GitHub Free. A custom domain is optional and not required.
