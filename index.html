Finance / Automation

Automated trading system

Personal project

A Python-based system that analyses market data and news sentiment, then independently executes trades in a paper-trading environment.

Project details

The system combines historical price data, technical indicators and sentiment analysis of daily financial news. Rather than only generating alerts, it makes simulated investment decisions and executes trades through a paper-trading account.

Paper-trading test: approximately 2–3% monthly return over a three-month testing period. This is a simulated result, not a live-investment track record or a guarantee of future performance.

Tools: Python, pandas, financial data APIs, NLP, technical indicators.

NLP / Text Analysis

Analysis of Lithuanian parliamentary transcripts

Team project

Using natural language processing to explore how topics, sentiment and key phrases in Seimas transcripts differ across parliamentary terms.

Project details

The coursework focuses on Lithuanian Seimas transcripts and compares material from the 2016–2020 and 2020–2024 periods. The analysis looks at recurring topics, sentiment and characteristic phrases to identify similarities and changes in parliamentary discussions.

Focus: text preprocessing, NLP, topic exploration, sentiment analysis and key-phrase extraction.

NLP / Topic Modelling

Exploring themes in song lyrics

Team project

Comparing topic-modelling methods to identify recurring themes in pop, rap and rock lyrics.

Project details

The project compares LSA, NMF and LDA across lyrics from selected artists and genres. It also examines how preprocessing choices — including removing choruses — affect the resulting topics.

Tools: Python, NLP, LSA, NMF, LDA.

Machine Learning / Computer Vision

Muffin or chihuahua?

Personal project

Training a convolutional neural network to distinguish between images of muffins and chihuahuas.

Project details

The dataset contained 5,917 images split into training, validation and test sets. The CNN was trained on resized images and evaluated on a held-out test set.

Test accuracy: 77.23% in the recorded experiment.

Tools: Python, TensorFlow / Keras, NumPy, Matplotlib.
